01

Kenapa Fetchly?

Gratis dan terbuka

Lisensi MIT. Tidak ada langganan, kredit, atau kunci aktivasi. Kodenya bisa kamu baca dan ubah sendiri.

Tanpa iklan dan pelacakan

Tidak ada analytics, cookie pihak ketiga, atau pengumpulan data. Halaman ini pun tanpa skrip pelacak.

Berjalan di komputermu

Aplikasi lokal menghubungi YouTube atau TikTok secara langsung untuk mengambil video yang kamu minta.

Tanpa batas server

Kecepatan mengikuti koneksimu. Batas durasi dan ukuran bisa diubah sendiri lewat file pengaturan.

02

Instalasi di Windows

Empat langkah, sekitar sepuluh menit. Kamu tidak perlu menulis kode.

  1. 1

    Pasang Python

    Unduh Python 3.11 atau lebih baru dari python.org. Saat pemasangan, centang Add Python to PATH.

  2. 2

    Pasang ffmpeg

    Buka PowerShell, jalankan perintah berikut, lalu tutup dan buka kembali terminal.

    winget install Gyan.FFmpeg

  3. 3

    Unduh kodenya

    Ambil arsip ZIP dari GitHub, lalu ekstrak ke folder yang mudah diingat, misalnya Dokumen\Fetchly.

    Unduh ZIP proyek

  4. 4

    Jalankan aplikasinya

    Buka terminal di folder proyek, lalu jalankan dua perintah ini. Browser akan terbuka otomatis.

    pip install -r requirements.txt
python run.py

Panduan lengkap, konfigurasi, dan solusi masalah umum ada di README.

03

Mengapa berjalan lokal?

Privasi yang jelas

Tidak ada server perantara yang menyimpan tautan atau filemu. Aplikasi hanya tersedia di 127.0.0.1, sehingga perangkat lain di jaringan tidak bisa membukanya.

Tanpa antrean

Unduhan memakai koneksi internetmu sendiri. Tidak ada batas kuota harian atau antrean pengguna lain.

Kendali penuh

File sementara dihapus setelah diunduh. Pengaturan batas durasi, ukuran, dan folder temp tersimpan di komputermu.

Fetchly.

Gunakan hanya untuk video yang kamu miliki haknya, video berlisensi yang boleh diunduh (misalnya Creative Commons), atau video yang diizinkan pemiliknya. Patuhi Ketentuan Layanan YouTube dan TikTok serta hukum hak cipta yang berlaku.
